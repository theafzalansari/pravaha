# PRAVAHA — AI Crowd Intelligence & Emergency Management

> Observe. Predict. Prevent. Protect.

PRAVAHA is an AI-powered crowd intelligence and emergency management platform built for large-scale gatherings such as Kumbh Mela.

## Web Application

This directory contains the React 18 + TypeScript frontend for PRAVAHA.

- **Command Center Dashboard**: Real-time crowd density, occupancy metrics, sector health, and AI risk distribution.
- **Crowd Risk Map**: Interactive OpenStreetMap / Leaflet view of Panchavati sectors (Zone A, B, C).
- **Live Camera Intelligence**: Video streaming with AI vision bounding boxes and density overlay.
- **Emergency IVR System**: Incident report hotline management and automated broadcasting.
- **Analytics & Trends**: Historical congestion analysis and predictive modeling.
- **Responsive Mobile Support**: Built-in mobile drawer navigation, dark/light theme switching, and touch-optimized controls.
